# LLDP-MIB Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The device answers LLDP-MIB `lldpLocPortTable` and `lldpRemTable` over SNMP, so LibreNMS shows its switch and port (r169, ge-0/0/9.0) on the device's Neighbours page.

**Architecture:** `lib/lldp` keeps the raw values the tables need next to today's display text. `lib/snmp_agent` gets an `SnmpLldpState` (reached by pointer from `SnmpDeviceState`, so no large copy lands on core 0's stack) and 12 fixed-OID entries; rows without a neighbour report noSuchInstance like ambientTemperature does. `src/` copies the neighbour into a static `SnmpLldpState` per request.

**Tech Stack:** C++ (Arduino-Pico 5.4.3), Unity native tests, net-snmp tools in WSL, Python HIL, LibreNMS in Docker.

**Spec:** docs/superpowers/specs/2026-11-01-lldp-mib-design.md

## Global Constraints

- lldpLocPortTable `1.0.8802.1.1.2.1.3.7.1`, row 1: `.2.1` subtype 3, `.3.1` 6 MAC bytes, `.4.1` "W5500 10/100 Ethernet"; always present.
- lldpRemTable `1.0.8802.1.1.2.1.4.1.1`, instance `.0.1.1`, columns 4-12 (chassis subtype, chassis id raw, port subtype, port id, port desc, sys name, sys desc, caps supported, caps enabled as 2-byte OCTET STRING); present only with a neighbour.
- Port ID rule: subtype 7 + non-empty Port Description → serve subtype 5 and the description; otherwise the raw subtype and bytes.
- Caps: IDs 64 bytes, System Description 128 bytes, raw; text fields as today.
- v1 and v2c see the same objects; absent row: v1 noSuchName, v2c noSuchInstance; GetNext/GetBulk skip it.
- `1.0.8802...` sorts before `1.3.6.1...`; mib-2 and enterprise walks unchanged.
- No large struct on core 0's stack: `SnmpLldpState` is static and reached by pointer.
- LibreNMS: only change `autodiscovery.xdp` to false (run as the `librenms` user). Never `docker compose down -v`.
- Version 2.7.0; docs: MIB.md, README, LIBRENMS.md, CHANGELOG, TODO, TESTING.md. Device settings restored after HIL (community rfit).

## Review Focus

1. No neighbour: a walk of `1.0.8802.1.1.2` returns only the 3 lldpLocPortTable objects and then continues into system (v1 and v2c, GetBulk too) — Task 2 `test_walk_without_neighbour_skips_rem_table`.
2. Get on a lldpRemTable column with another index (`.9.0.1.2`): v2c noSuchInstance, not noSuchObject — Task 2 `test_rem_column_other_index_is_no_such_instance` (needs `indexArcs`).
3. A Chassis or Port ID longer than 64 bytes, a 255-byte System Description: cut, not overrun — Task 1 `test_parse_keeps_raw_ids_cut_to_64` / `test_parse_cuts_sys_descr_to_128`.
4. Subtype 7 Port ID with no description: raw "523" is served, not an empty string — Task 1 `test_snmp_port_id_without_description_is_raw`.
5. The neighbour changes or expires between captureState() and the response: the response is built from the static copy taken under the lock, never from the live table — Task 4 code review (copy in `lldpServiceSnmpState`, one copy per request).

- Produces:
  ```cpp

      uint8_t localMac[6];
      bool present;                // a neighbour is held
  ```
