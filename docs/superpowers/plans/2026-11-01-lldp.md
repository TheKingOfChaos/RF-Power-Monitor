# LLDP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The device announces itself over LLDP (so the Juniper EX2200-C lists it as a neighbour) and shows the switch and port it hears on the serial status screen and the web page.

**Architecture:** A new pure library `lib/lldp` builds LLDPDUs, parses received ones, keeps one neighbour with TTL expiry, formats the display text, and decides when to send. `src/lldp_service.cpp` runs it on core 0: received frames come from the existing input hook in `src/net_stats.cpp`, frames go out with `netStatsSendFrame()`. `lib/if_stats` stops counting LLDP as an unknown protocol.

**Tech Stack:** C++ (Arduino-Pico 5.4.3, lwIP 2.2.1, W5500 MACRAW), Unity native tests, Python HIL tests (pyserial).

**Spec:** docs/superpowers/specs/2026-11-01-lldp-design.md

## Global Constraints

- LLDPDU to 01:80:C2:00:00:0E, EtherType 0x88CC, source = device MAC; every 30 s; TTL 120 s.
- TLVs sent, in order: Chassis ID (subtype 4, MAC), Port ID (subtype 3, MAC), TTL 120, Port Description "W5500 10/100 Ethernet", System Name = `hostnameCurrent()`, System Description = sysDescr text, System Capabilities (station only: capabilities 0x0080, enabled 0x0080), Management Address IPv4 if any, Management Address IPv6 (global) if any (interface subtype 2 = ifIndex, number 1, OID length 0), End.
- Send also 1 s after the link comes up and whenever the frame content changes, at most one frame per second. No TTL 0 frame on reboot.
- One neighbour; latest wins. Forgotten on TTL expiry, TTL 0, or link down.
- Port text: Port Description when Port ID subtype is 7 and a description is present, else the Port ID. Name: System Name, else Chassis ID.
- Received text is cut to 64 bytes and every byte outside 0x20..0x7E becomes `?`; the web page HTML-escapes it.
- Nothing over ~256 bytes on core 0's stack: neighbour structs and frame buffers are static.
- LLDP always on, no settings. No LLDP-MIB, no CDP, no org TLVs sent.
- Pure code in `lib/lldp` (no Arduino includes); native builds with `-Wall -Wextra -Werror`; added to `scripts/sanitize.sh`.
- Version 2.6.0. Docs: README, CHANGELOG, TODO, docs/TESTING.md, docs/MIB.md.
- HIL: `RFUPS_LLDP_SWITCH=1` (listening), `RFUPS_LLDP_SWITCH_CONSOLE=<port>` (switch console, credentials from `secret/switch.md` or `RFUPS_LLDP_SWITCH_CREDENTIALS`, never printed). Operational commands only on the switch.

## Review Focus

1. A TLV whose length runs past the end of the frame, or a frame cut inside the TLV header: dropped, nothing read past the end (Task 2, `test_parse_rejects_tlv_past_end`, `test_parse_rejects_cut_tlv_header`).
2. Text with control bytes, `<script>`, or 255 bytes long shown on the web page: cut and escaped (Task 2 `test_parse_sanitises_and_cuts_text`, Task 5 `test_status_page_escapes_switch_name`).
3. millis() wrap while a neighbour is held: it still expires after its TTL (Task 2, `test_neighbour_expires_across_millis_wrap`).
4. The hostname changed or an address arrives right after a send: the update goes out within about 1 s, not 30 s (Task 3, `test_changed_content_sends_after_one_second`).
5. Link flaps: the old neighbour is forgotten on link down, and a fresh frame goes out 1 s after link up (Task 3 `test_link_flap_restarts_the_one_second_wait`; the link-down `clear()` call in `lldpPoll` is checked in the final review, since unplugging the cable is not automated).

  static const size_t LLDP_TEXT_MAX = 64;
  struct LldpNeighbour {
      char chassisId[LLDP_TEXT_MAX + 1];  // MAC subtype as aa:bb:cc:dd:ee:ff, else sanitised text
      uint8_t portIdSubtype;
      char portId[LLDP_TEXT_MAX + 1];     // same rules
      char portDescr[LLDP_TEXT_MAX + 1];
      char sysName[LLDP_TEXT_MAX + 1];
      char mgmtAddr[46];                  // first IPv4 or IPv6 management address as text, empty if none

  enum class LldpParse : uint8_t { Ok, NotLldp, Malformed };
  LldpParse lldpParseFrame(const uint8_t* frame, size_t len, LldpNeighbour& out);
  class LldpNeighbourTable {
  public:
      void received(const LldpNeighbour& n, uint32_t nowMs);  // ttl 0 clears
      void expire(uint32_t nowMs);
      void clear();
      bool present() const;
      const LldpNeighbour& neighbour() const;

  /// "<name>, port <port>" (rules in Global Constraints), or "none seen" when absent
