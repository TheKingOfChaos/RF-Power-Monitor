## Changing a diagram

The `.excalidraw` files are generated by [make_diagrams.py](make_diagrams.py), which places the boxes and binds the arrows to them. Either edit the script and regenerate, or edit a file in Excalidraw; regenerating overwrites hand edits, so pick one.

Layout rules, checked when the script runs (it prints a warning for each break): arrows run straight or in orthogonal steps through the gaps between boxes, never along a box edge or zone border and never through a box or a text; no segment is shorter than 30 px; an arrow's label is free text beside its segment (above a horizontal one, right of a vertical one), grouped with the arrow, so no line or arrowhead crosses it.

```powershell
python docs/diagrams/make_diagrams.py                 # .excalidraw files
wsl -d Ubuntu-24.04 -- bash docs/diagrams/render_svg.sh   # .svg files (needs Docker and internet)
# Without Docker inside WSL: run the docker command from render_svg.sh on Windows, with docs/diagrams mounted at /diagrams
```

`render_svg.sh` runs [render.mjs](render.mjs) in the Playwright Docker image: headless Chromium loads Excalidraw 0.17.6 and exports each file with Excalidraw's own `exportToSvg`, then the hand-drawn Virgil font is embedded so the SVGs look the same on GitHub. After editing a diagram in Excalidraw, run only `render_svg.sh`, or export the SVG from Excalidraw yourself (Export image → SVG, with "Embed scene" off).
